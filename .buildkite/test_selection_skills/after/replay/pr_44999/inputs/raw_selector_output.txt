This PR refactors weight loading for ColBERT embedding models. It replaces manual prefix stripping logic with new utilities (`AutoWeightsLoader`, `WeightsMapper`) in four ColBERT model classes. The change only affects how weights are loaded from checkpoints, not the model architecture or forward pass. I'm selecting tests that load and exercise ColBERT models, plus the late interaction tests that depend on ColBERT functionality. Dropping all candidates that only import the module but don't actually instantiate or test ColBERT models (generation tests, kernels, LoRA, compilation, etc.).
