The change is isolated to request protocol parsing and the tokenization parameter handling in `vllm/renderers/params.py`.

- The new parameter is optional and backward-compatible
- Only affects behavior when explicitly set alongside `truncate_prompt_tokens`
- Tests were already added in the modified test files
- Changes are confined to the entrypoints/openai and renderers areas
