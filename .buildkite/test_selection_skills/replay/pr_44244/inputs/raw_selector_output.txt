This PR adds support for passing `chat_template_kwargs` through the benchmark infrastructure to tokenizers. It threads a new optional parameter through the dataset handling code, adds a new CLI argument to serve.py, and includes a new test to validate the feature. The changes are backward-compatible (the parameter defaults to None) and limited to benchmark/dataset code paths. I'm selecting the new test file, the direct dataset tests that exercise the modified functions, and the CLI benchmark tests that validate the serve.py changes.
