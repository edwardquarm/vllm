This PR removes sparse attention kernel code (`vertical_slash_index.cu`), MOE-related Marlin bindings, and their Python wrappers. The changes are deletions of unused or deprecated code paths, affecting C/C++/CUDA source files and their Python bindings.

The key changes:
- Deleted `csrc/attention/vertical_slash_index.cu` (sparse attention kernel)
- Removed `convert_vertical_slash_indexes` functions from `_custom_ops.py`
- Removed `marlin_gemm_moe` bindings (replaced by `moe_wna16_marlin_gemm`)
- Updated `CMakeLists.txt` to remove kernel from build

Per Rule 3, `CMakeLists.txt` and `csrc/` changes trigger kernel and basic correctness tests. Since these are code removals rather than logic changes, I'm narrowing the candidate set to only tests that could directly exercise these deleted code paths.
