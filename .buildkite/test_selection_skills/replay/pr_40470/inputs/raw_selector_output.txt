This PR refactors the CPU attention backend by extracting KV cache update logic from the `forward()` method into a separate `do_kv_cache_update()` method. The change also adds a class variable `forward_includes_kv_cache_update` to signal that updates happen separately, and removes the `isa` field from the `CPUAttentionMetadata` dataclass. This is a structural refactoring of a core attention component, so tests that exercise CPU attention and attention backend selection are at risk if the method call or dataclass removal breaks dependent code.

---
tests/kernels/attention/test_cpu_attn.py | directly tests CPU attention implementation
tests/v1/attention/test_attention_backends.py | tests attention backend selection and metadata
tests/basic_correctness/test_basic_correctness.py | core functionality regression test
