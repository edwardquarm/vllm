This PR modifies the `AttentionGroupKey` deduplication logic in the GPU model runner's attention initialization, adding a new `num_heads_q` field to handle spec_decode scenarios where draft models have different attention head counts than target models. The change ensures layers with different Q-head counts get separate metadata builders. The `.buildkite/test_areas/spec_decode.yaml` update explicitly signals that spec_decode tests should now depend on attention backend changes.
