This PR adds configurable flex attention block sizes (BLOCK_M, BLOCK_N, Q_BLOCK_SIZE, KV_BLOCK_SIZE) to enable tuning for batch invariance. The changes are backward-compatible (all new config fields are optional) and validation only triggers when VLLM_BATCH_INVARIANT=1 or when the FLEX_ATTENTION backend is explicitly used.

The diff shows:
- New optional AttentionConfig fields for flex attention tile sizes
- Validation in Attention.__init__ when using FLEX_ATTENTION backend
- FlexAttentionImpl refactored to support configurable block_m/block_n parameters
- Test parametrization to verify batch invariance across different block sizes
