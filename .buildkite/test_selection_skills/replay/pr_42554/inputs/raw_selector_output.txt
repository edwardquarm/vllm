This PR modifies two core v1 components: the NIXL KV connector worker's prefix caching logic and the scheduler's Mamba block alignment handling with async receive. The worker.py change adds support for SSM prefix caching with placeholders and partial FA prefix cache hits. The scheduler.py change removes an assertion and adds a condition to skip block-aligned splitting during async KV receive setup. The test file for the connector was updated with a new parametrized test for these scenarios. Selection includes direct unit tests of both modified components, async-specific scheduler tests (which are directly affected by the new condition), and e2e tests that exercise these paths in integration.
