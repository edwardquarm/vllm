This PR modifies the NIXL KV connector's prefix caching logic to handle SSM blocks with placeholders and adds a new test for this scenario. The changes also relax an assertion in the scheduler's mamba block alignment to allow external KV transfer during async receive. The new test in `test_nixl_connector_hma.py` directly exercises the updated `_apply_prefix_caching` method. Other KV connector tests that use this worker, and scheduler tests for mamba prefix caching, are the primary candidates. LoRA and quantization tests are unrelated to KV connector internals and can be dropped.
