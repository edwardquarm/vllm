This PR adds backend registration and override capabilities to the MLA prefill backend system. The changes include a new `CUSTOM` enum member, override mechanisms (`_MLA_PREFILL_OVERRIDES`, `is_overridden()`, `clear_override()`), and a new `register_mla_prefill_backend()` function. A new test file (`test_mla_prefill_registry.py`) directly tests this registration system. The changes are to low-level registry infrastructure with backward-compatible behavior—existing code that doesn't use the override mechanism should work the same way. I'll include the new test file plus MLA-specific tests to verify the registration system works and doesn't break existing backend selection.
