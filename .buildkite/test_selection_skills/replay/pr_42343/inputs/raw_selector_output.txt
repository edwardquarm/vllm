This PR modifies the DP Coordinator's `_wait_for_zmq_addrs()` method in `vllm/v1/engine/coordinator.py`. The changes are: extracting the timeout value from hardcoded 30 to a configurable 120 seconds, and enhancing the error message to include the timeout value. This is a localized change to the startup/initialization path for distributed data parallelism. While the candidate table is extensive (200+ tests), most are unaffected since they don't exercise DP coordination. The relevant tests are those that directly test engine initialization and DP coordination.
